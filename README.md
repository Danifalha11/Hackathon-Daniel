# COMO USAR O PROGRAMA:
# Primeiro aperte as teclas Ctrl + J para abrir o terminal, nele digite "pip install mysql-connector-python" e aperte a tecla Enter. Após isso, abra o arquivo SQLxPython.py e rode ele, caso nada apareça, deu tudo certo. Depois de tudo isso, você pode entrar na main.py e rodar.

# NA main.py
# Cadastre uma conta usando a opção "Criar uma conta", apertando 2, com usuário de 5 a 25 caracteres e uma senha de pelo menos 8 caracteres (lembre-se de que na senha deve conter pelo menos um número e um caractere especial (como !@#$%)). Após o cadastro, use a opção "Já tenho uma conta" apertando 1 e faça o login com a conta que você criou

# NO MENU
# Dentro do menu, você pode: ver seu perfil, ver o placar com os usuários, atualizar sua conta (deve sair e logar de novo para mudar visualmente), excluir a sua conta, sair e, o mais importante, o ReciclaQuiz, que é um quiz simples de 3 níveis sobre sustentabilidade. Cada nível tem 5 perguntas, os níveis são divididos em: 1 - Fácil, 2 - Médio e 3 - Difícil, os níveis tem uma pontuação mínima para serem jogados (0, 5 e 10) e o usuário tem 3 chances para erros. Caso as chances acabem, o usuário ainda recebe os pontos e é redirecionado ao menu inicial.
